# CiviSort — A Road Safety Website

CiviSort helps answer three questions: which road hazards matter most, which repairs fit within our budget, and whether those repairs were actually completed. Residents report hazards; reviewers verify them; the app explains priorities, selects a repair bundle, and records the repair history.

This product is a **local Flask/SQLite prototype**, using synthetic reports. Scores are planning assumptions, not measured accident risk or accident predictions.

## Main features

- **Hazard reporting:** choose a location on the map or schematic, describe a hazard, and optionally attach a photo. Evidence status is tracked separately from repair status.
- **ContextShift:** simulate Rain, Night, and School Hours. Matching conditions change relevant priorities; multiple conditions do not stack.
- **Priority Breakdown:** inspect the backend's severity, exposure, vulnerability, conditions, and age contributions.
- **BudgetMix:** select eligible verified repairs within an INR budget, compare with a priority-first baseline, and save a plan snapshot as Reviewer. Costs round up and budgets round down to INR 1,000 units.
- **Repair Receipt:** residents claim a planned repair with a note or after-photo; reviewers confirm closure or reopen it with a reason. History records timestamps.
- **Duplicate review:** same-category reports within 50 metres are flagged for reviewer-confirmed merging; linked duplicates remain on record.

## Technology and requirements

Python **3.11+**, Flask, SQLite, Pillow, pytest, HTML/CSS/JavaScript, and bundled Leaflet 1.9.4. Exact Python dependency versions are in [requirements.txt](requirements.txt); no Node.js or JavaScript build step is required.

The included launcher scripts target **Windows 10/11**. Install Python from [python.org](https://www.python.org/downloads/) with **Add python.exe to PATH** enabled, then use a modern browser. Internet is required for the **first dependency installation**. Online OpenStreetMap tiles also need internet; the app includes a labelled local schematic fallback.

## Start, stop, and restart

On Windows, double-click **run.bat**, or run this from Command Prompt in the repository folder:

```bat
run.bat
```

The launcher creates `.venv`, installs `requirements.txt`, and starts the local server. Keep its console open and visit **http://127.0.0.1:5000/**.

First startup creates the database and about 20 synthetic reports, illustrative photos, and demonstration plan snapshots. Seed photos are generated by code; no prebuilt database or upload directory is required. Data is stored in `data\civisort.sqlite3` and `data\uploads\` and is excluded from Git.

To stop, press **Ctrl+C** in the server console. To restart, run **run.bat** again. Reports and plans are retained; seeding occurs only when there are no reports. The launcher runs pip on each start, so it may contact the package index again.

For Linux/macOS, the equivalent commands are:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

## Five-minute judge demonstration

1. Select a seeded hazard from the list or map; inspect evidence, repair status, and priority breakdown.
2. Toggle Rain, Night, or School Hours and compare relevant rankings.
3. As **Resident**, click a map location and submit a hazard; it starts unverified.
4. Switch to **Reviewer**, set severity, exposure, vulnerability, and cost, then verify evidence.
5. Adjust BudgetMix's budget and save a plan snapshot as Reviewer; selected reports become Planned.
6. As Resident, claim a Planned repair with a completion note or after-photo. As Reviewer, confirm closure, inspect History, and reopen with a reason if desired.

See [START_HERE.md](START_HERE.md) for judge setup and [DEMO_GUIDE.md](DEMO_GUIDE.md) for the detailed walkthrough.

## Tests and validation

On Windows:

```bat
run_tests.bat
```

Or, after installation:

```bat
.venv\Scripts\python.exe -m pytest -q
```

Linux/macOS: `.venv/bin/python -m pytest -q`.

Existing tests use temporary databases. They cover scoring, scenario rules, budget optimisation against exhaustive search, eligibility, permissions, workflow transitions, duplicate handling, image/input validation, saved snapshots, fresh seeding, and persistence.

Submission preparation verified **76 passing tests on Python 3.12.14/Linux**, dependency consistency, fresh startup, and restart persistence. Windows batch execution was not available in that environment; the scripts were inspected.

## Troubleshooting and map fallback

| Problem | What to check |
| --- | --- |
| Python is not recognised | Install Python 3.11+ with PATH enabled or the `py` launcher; reopen Command Prompt and rerun `run.bat`. |
| Package installation fails | Check internet/proxy access to PyPI and rerun. Do not skip dependency installation errors. |
| Browser cannot connect | Wait for the startup message, keep the console open, and check its errors. Use `http://127.0.0.1:5000/`. |
| Port 5000 is in use | Stop an earlier CiviSort server or the other process using that port, then restart. |
| Online map tiles fail | Wait for the labelled local schematic. Pins remain selectable and clicking the schematic selects a reporting location. |
| Tests cannot import dependencies | Complete installation first, then run pytest through `.venv`'s Python as shown above. |

Leaflet, the schematic, CSS, and JavaScript are bundled. Online tiles are optional and attributed to OpenStreetMap; no tile archive is included.

## Reset the demo — deletes your data

**Warning: resetting permanently deletes existing reports, history events, saved plans, and uploaded photos in the configured data directory, then recreates synthetic demo data. Stop the server and back up anything you want to keep first.**

On Windows, run **reset_demo.bat** after the first installation and type **RESET** at its confirmation prompt. Restart with `run.bat` afterwards.

Linux/macOS equivalent: `.venv/bin/python -m civisort.seed --reset`. This direct command **does not ask for confirmation**.

The optional `CIVISORT_DATA_DIR` environment variable selects a separate data directory; set it before starting or resetting. A reset applies to that directory if configured.

## Prototype limitations and disclosure

- **All seed reports, photos, and plans are synthetic demonstration material.** The schematic is illustrative, not a surveyed map; reporting coordinates are restricted to the demo ward.
- Resident/Reviewer is a **demo role switch**, not secure accounts. Anyone using the page can change role. The fixed local-demo session key is not a production credential.
- Scoring weights and cost estimates are assumptions, not calibrated safety evidence. Duplicate proximity is approximate, and merges cannot be undone through the interface.
- Photo uploads are checked for type, size, and pixel limits and re-encoded without metadata; there is no malware scanner.
- This uses Flask's development server bound to `127.0.0.1`, with no production deployment or public-hosting claim.
